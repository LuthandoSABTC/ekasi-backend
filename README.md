#Bitcoin Ekasi Backend

A simple proxy server that forwards requests from the Bitcoin Ekasi Diploma Tracker to the Blink Lightning API, bypassing browser CORS restrictions.

## Deploy on Render

1. Push this repo to GitHub
2. Go to render.com → New Web Service
3. Connect your GitHub repo
4. Build command: `npm install`
5. Start command: `node server.js`
6. Click Deploy

That's it!
